# Netflix ER Diagram

## Project Overview
This project demonstrates the design of a relational database for a Netflix-style dataset using an Entity Relationship (ER) Diagram.

## Objective
The goal was to organize the Netflix dataset into multiple related tables while reducing redundancy and improving data integrity through normalization.

## Tools Used
- Draw.io (diagrams.net)
- Relational Database Design
- Entity Relationship Modeling

## Database Entities
- Netflix Titles
- Rating
- Cast
- Directors
- Category
- Country

## Skills Demonstrated
- Database Design
- Entity Relationships
- Primary Keys
- Foreign Keys
- Database Normalization
