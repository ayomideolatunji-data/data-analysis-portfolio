# 🛒 Sales Data Analysis with Python

## 📌 Project Overview

This project analyzes a retail sales training dataset using Python to uncover sales trends, customer behavior, product performance, and regional sales patterns. The analysis follows a complete data analysis workflow, from data exploration and cleaning to visualization and business insight generation.

---

## 🎯 Objectives

- Explore the training dataset.
- Clean and prepare the data for analysis.
- Analyze sales performance across customer segments, product categories, and regions.
- Identify sales trends over time.
- Present findings through data visualizations.

---

## 🛠️ Tools & Technologies

- Python
- Pandas
- Matplotlib
- Jupyter Notebook

---

## 📂 Dataset

This project uses the **`train.csv`** dataset obtained from Kaggle.

---

## 📊 Analysis Workflow

- Data Exploration
- Data Cleaning
- Data Filtering
- Data Sorting
- Data Aggregation & Grouping
- Exploratory Data Analysis (EDA)
- Data Visualization
- Business Insight Generation

---

## 📈 Key Findings

- The **Consumer** segment contributes **50.76%** of total sales.
- **Technology** is the highest-performing product category.
- The **West** region generates the highest overall sales.
- Sales increased steadily between **2015 and 2018**.
